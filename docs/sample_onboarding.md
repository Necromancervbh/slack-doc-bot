# New Employee Onboarding Guide

## Week 1 Checklist

- Complete IT setup: laptop, email, Slack, VPN
- Attend company orientation session
- Meet your onboarding buddy
- Review the handbook and FAQ
- Set up 1:1 meetings with your manager

## Dev Environment Setup

### Prerequisites

- Python 3.11 or higher
- Node.js 20 or higher
- Docker Desktop
- VS Code or PyCharm

### Steps

1. Clone the main repository:
   git clone https://github.com/company/main-repo.git

2. Install Python dependencies:
   pip install -r requirements.txt

3. Copy .env.example to .env and fill in credentials from 1Password.

4. Run the dev server:
   docker-compose up
